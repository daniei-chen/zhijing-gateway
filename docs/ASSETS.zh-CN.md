- 原 Sub2API 图标、各厂商品牌标识和 Vue 业务组件保持其原依赖/原许可，不声称为智境原创资产。
- 没有新增外部字体 CDN、分析服务、位图背景、WebGL、自动播放或额外运行依赖。
- README 浅色/深色封面为本工程绘制的原生 SVG，不属于运行时背景；展示截图全部来自本机合成数据预览。

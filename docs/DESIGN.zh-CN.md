# 智境前端设计语言

智境延续首页的浅灰白、石墨文字、紫色 Z 与无衬线字阶。V5/V6 引入紫蓝青色光场、浮岛导航、半透明表面和细高光边缘。

| 层次 | 表现方式 |
| :--- | :--- |
| 外框 | 小面积玻璃导航和顶栏，选中项使用独立滑块。 |
| 数据 | 图表和表格采用清晰底色，固定列保持不透明；不在滚动单元格上堆叠模糊。 |
| 浮层 | 弹窗、下拉与行操作使用统一圆角、高光和玻璃材质，保留原定位及层级。 |
| 反馈 | 轻微按压、悬停与进出场；系统减少动态效果和手动暂停都生效。 |
| 状态 | 紫色标识重点操作，健康/危险/告警继续保留原语义色。 |

管理员扩展样式位于 `frontend/src/styles/zhijing-admin-glass.css`，由 `.z-admin-workspace` 与当前管理页面限定；传送到 body 的浮层使用相同作用域。成员和登录内容沿用 V5。

共用弹窗支持顶层焦点循环，跳过隐藏、禁用及负 tabindex 控件；外置下拉菜单保留自身键盘处理，多层弹窗由最上层接收焦点边界。Escape 关闭和原触发位置恢复保持。

390px 与 320px 下，原生宽表格切换卡片；表单输入字号为 16px，按钮保留触控面积。背景模糊不可用时采用原生实色回退。

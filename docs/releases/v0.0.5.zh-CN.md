# v0.0.5 · 后端随上游升级，交互保持原样

本版是**后端升级版**。后端跟随上游 [Sub2API](https://github.com/Wei-Shaw/sub2api) `v0.2.20`（`6b4b37db`，96 个提交、388 个文件）并恢复智境的行为层；前端与 v0.0.4 完全一致（346 个静态文件，未重新构建）。所以本版不含新的界面与交互，升级只涉及后端与入口权重。

| 改进 | 实际行为 |
| --- | --- |
| 上游稳定性合入 | WS 连接池与租约、SSE 限制、鉴权与会话、计费模式、迁移校验、观测口径等 96 个上游提交。 |
| 智境行为保留 | 256 MiB 请求体预算、120s 单次读/写停滞、30s 断连 drain、25 分钟转发上限、关键词与管理豁免、并发 3/9/9。 |
| 本地增补修复 | 配置键守护（防 `security.*` 静默失效）、迁移回滚开关（`ZHIJING_ALLOW_UNKNOWN_APPLIED_MIGRATIONS`，默认关）、预算记账、drain 优先级。 |
| 迁移一致 | 生产库 `schema_migrations` 300 条与源码 300 个文件一致；启动校验通过，**无新增迁移**。 |

## 下载与升级

本版 Release 提供三个资产：

1. `v0.0.5-upstream-0.2.20.patch`（及集成清单与说明，打包为 ZIP）：相对上游 `6b4b37db` 的后端源码差异，176 个文件，SHA-256 `d6c0b66190c8850996a52ee1d3f0c32ba64994197d80c70fec84963a57d8ed04`，已在纯净上游树上验证可干净应用。
2. `BUILD-MANIFEST.json`：本版构建与验证摘要。
3. `SHA256SUMS.txt`：全部资产校验值。

```sh
python integrations/sub2api/check_patch.py --bundle v0.0.5 --artifact-only
python integrations/sub2api/check_patch.py --bundle v0.0.5 --root /isolated/matching-source --apply
```

**前端不需要更新。** 若你的实例仍在 v0.0.2/v0.0.3 前端，请先按 v0.0.4 的静态资源 ZIP 升级前端，再应用本版后端补丁；本版兼容 v0.0.4 及之后的前端。升级顺序与回滚要求见[线上部署记录](docs/deployments/v0.0.5-2026-11-08.zh-CN.md)。

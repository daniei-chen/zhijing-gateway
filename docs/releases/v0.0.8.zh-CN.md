# v0.0.8 · 智境网关高效稳定升级

v0.0.8 基于上游 Sub2API v0.2.21，并保留智境 v0.0.7 已验证的计费、告警与深度就绪修复。生产升级采用蓝绿/灰度切换，旧实例保留为回滚入口。

## 本版变更

- 对带有可信 `Content-Length` 且不超过 8 MiB 的请求体做受限预分配，减少常见多 MiB 请求的分块分配与最终拼接复制。
- 继续使用请求体共享内存预算、压缩解码上限和全局请求体大小限制；超过预分配范围仍走原有受控分块路径。
- 版本元数据统一为 `0.0.8`，并随构建注入 commit 与构建时间，支持线上实例追溯。
- 同步上游 v0.2.21 的请求体自适应预算、usage log 索引、缓存 TTL、刷新令牌原子轮换、调度槽位释放、模型冷却、Codex 元数据重试/故障转移和 Responses UTF-8 错误处理等修复。
- 保留智境 v0.0.7 的计费失败留痕、余额缓存安全回填、资金对账指标、告警样本门槛和 `/readyz` 数据库/Redis 深度检查。

## 验证

本版已完成以下本地验证：

- `go test ./...`
- `go vet ./...`
- 请求体预算、超时、路由、网关 handler 相关测试
- 前端 i18n 检查、TypeScript 构建和 Vite 生产构建
- 生产灰度期间 `/health`、`/readyz`、鉴权、模型列表与真实 Responses 流量检查

验证结果支持本版上线，但不把有限采样表述为“绝对无漏洞”或“绝对无 bug”。上线后仍需持续观察错误率、首字节延迟、客户端断开、上游 429/5xx、内存和磁盘。

## 部署与回滚

升级使用新端口启动 v0.0.8，健康检查通过后先小比例导流，再切换为主流量；原生产实例保持运行作为备用。回滚时将 Nginx upstream 恢复到备用实例并 reload，随后复核 `/readyz` 和公开 HTTPS 探针。

发布资产包含源码归档、前端嵌入产物和 SHA-256 校验文件。部署前应核对镜像版本、commit、迁移状态及资产校验值。

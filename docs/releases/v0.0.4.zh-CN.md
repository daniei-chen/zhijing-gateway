# v0.0.4 · 交互有序，发布有据

延续智境的紫蓝青、液态玻璃和清晰排版，合并此前未正式发布的 v0.0.3 会话、生命周期与诊断修复，并修复最后一批实际操作问题。本版在原四项全局 80% 覆盖率门槛全部通过后交付，生产服务保持原版本。

| 改进 | 实际行为 |
| --- | --- |
| 首次打开即可用 | 账号创建的 TLS 选项、账号测试模型和错误规则列表在条件挂载的第一次打开时加载。 |
| 预设选择保持准确 | MiniMax 国际端点在模式和协议监听结束后保留明确选中的地址；关闭或切换目标后丢弃旧结果。 |
| 定时测试有归属 | 列表、结果、创建、修改和删除绑定账号、面板与登录会话；阻止重复提交，迟到反馈不覆盖新草稿。 |
| OAuth 冲突可以恢复 | 四种回调兼容实际客户端规范化后的 EMAIL_EXISTS 等精确状态，正确进入原有账号绑定流程。 |
| 支付跟进至入账 | PAID / RECHARGING 继续有限查询到 COMPLETED，再刷新一次余额；保留成功展示、恢复快照规则、2 秒间隔和 15 次上限，卸载后停止后续排程。 |
| 门禁与来源可核对 | 原兼容摘要链和四项 80% 门槛保留；锁定 Node 24 / pnpm 9.15.9，正式打包从干净提交重新验证并生成摘要。 |

| 覆盖率 | 实测 | 原门槛 |
| --- | ---: | ---: |
| 行 | 89.40% | 80% |
| 语句 | 86.66% | 80% |

此前 6,678 项全部通过但分支 79.66% 的运行保留为失败检查点，未当作门禁成功。新增用例通过原生 DOM、真实客户端和合成 HTTP 验证正常、拒绝、取消、迟到和恢复路径；未删除旧测试，也未降低覆盖范围或门槛。工具回归 53 项通过、1 项 Windows 条件跳过，Ops 合同 3 项通过。

最终打包器还会对已提交源码独立执行锁定安装、全仓 ESLint、生产构建、兼容契约、配套补丁和完整覆盖率；结果记录在发布资产 BUILD-MANIFEST.json。详见[验证摘要](../validation-v0.0.4.json)、[完整回归证据](../proofs/v0.0.4/frontend-validation-final.json)和[逐项源码修复记录](../proofs/v0.0.4/frontend-runtime-fixes.json)。

包含此前 v0.0.3 候选的 HttpOnly Cookie 与一次性 OAuth 交接、会话/异步隔离、图片资源清理、设置草稿保留、后台按需加载、导出快照、幂等重放，以及首字节、首事件和语义输出里程碑。原 API 路径、权限、计费、额度和推理档位保持。原审计说明的 Playwright 解析路径、测量 manifest 计数、浏览器范围、注册草稿 TTL 与 CPU 耗时倍率均按证据精确说明；历史数据不改写成本次新测量。

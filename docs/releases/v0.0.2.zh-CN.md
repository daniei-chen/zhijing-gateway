# v0.0.2 · 会话有界，诊断有据

这一版先处理两项前端安全边界，再补齐管理员运维诊断。延续智境紫蓝青光场、液态玻璃和清晰的阅读层次。

## 优先修复

- **操作属于发起它的会话。** 请求在发送时绑定会话代次；401 刷新、重试、成功响应、用户信息写回及退出都检查归属。旧账号的操作不会改用新账号凭证重发，晚到的结果不会覆盖或退出新会话。
- **换号清除旧页面状态。** 其他标签切换会话，或当前页面切换用户主体后，重新加载页面与状态，避免对旧表格或订阅缓存发起新账号操作。同一会话的正常 token 轮转继续复用页面。
- **嵌入页不再接收原登录 token。** iframe 与新窗口共用不含登录凭证的 URL；来源追踪不再携带回调查询参数或片段，并设置无来源导航策略。

依赖旧 `token` 查询参数的外部服务需要迁移。完整的短时、单次兑换票据协议需要服务端与接收方联调，**不在本版本中宣称已实现**。更新安全版本时应完整刷新旧标签；无法确认会话一致性时会停止请求，重新登录可重建会话。

## 运维增强

- 请求列表新增“请求时序”，将读取请求体、规范化、个人/账号/连接等待与入站里程碑分别呈现，保留原 `first_token_ms` 指标含义。
- 区分真实零等待和“未采集”；旧后端、跨进程查询、重启、到期或缓存淘汰均正常降级。
- 对可信本地并发拒绝提供具体提示；历史模板推断保留独立标识和原始归因，不改写历史统计。
- 修正自定义时间窗口传递、分页默认值和首事件解释，完善深色及手机排版。

## 验证与边界

前端全量回归覆盖登录、OAuth、二次验证、会话刷新、跨账号 GET/POST/PUT/DELETE、旧响应、同账号再次登录、嵌入 iframe/新窗口以及原有管理与成员页面。原四条失败的安全验收已转为通过；另有真实客户端、认证 API 与状态仓库的合成往返验证。

后端诊断完成 5 个包、196 个测试及子测试的定向回归、Go vet、Linux amd64 交叉构建；补丁在匹配的最小工作树完成检查、应用和结果摘要核对。认证、存储及上游依赖使用合成数据，没有执行付费推理或生产数据库操作。

原 v0.0.1 兼容基线保留。5 个受保护的认证/嵌入文件按明确安全补丁变更，3 个相关测试登记夹具及安全断言更新，1 个运维 API 文件只追加可选类型；其余 218 个受保护文件、68 条路由及两份运行时法律文本保持校验一致。根级 CI 执行冻结依赖安装、全部前端测试、构建和契约/产物检查。

GitHub 发布与生产部署分别记录：**本版本不执行生产切换**。完整后端鉴权、供应商与长时生产运行不属于此次本地验证的结论。其余体验及工程待办见 [审查核实](../reviews/2026-11-05-security-followup.zh-CN.md)。

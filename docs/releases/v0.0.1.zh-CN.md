# v0.0.1 · 智境液态玻璃前端

首个 GitHub 版本，收录智境登录、成员工作台与 V6 管理员内页的完整前端。

## 本次内容

- 登录、侧栏与顶栏延续智境紫蓝青光场、浮岛导航和液态玻璃表现。
- 管理员表格、筛选、按钮、表单及弹窗统一材质，保留固定列、虚拟滚动和原业务事件。
- 完成深色模式、320/390px 窄屏、减少动态效果及弹窗键盘焦点边界。
- README 提供双主题封面、实际界面截图、来源许可与独立运行说明；演示截图使用合成数据。

## 下载内容

| 文件 | 用途 |
| :--- | :--- |
| `zhijing-gateway-v0.0.1-frontend.zip` | 309 个静态构建文件及使用说明、许可、构建清单。 |
| `BUILD-MANIFEST.json` | 发布提交、前端源树与每个静态文件的 SHA256。 |
| `SHA256SUMS.txt` | ZIP 与构建清单的下载校验值。 |
| GitHub Source code | 此标签对应的完整前端源码与本机合成预览。 |

解压构建包后，`dist/` 是静态前端。资源使用 `/app-assets/`，与官网 `/assets/` 分开；使用现有网关的 API 与认证配置。接入时先上传静态资源，保留旧哈希文件和可恢复的 HTML 入口。独立预览的安装命令见仓库 README。

Node.js 24.19.0、pnpm 9.15.9 锁文件安装及构建通过；41 个测试文件、207 项界面回归通过。24 个管理入口完成本地浏览器检查。227 个核心契约文件、68 条路由和两份运行时法律文本保持校验一致，生产构建中不含合成身份及演示横幅。
